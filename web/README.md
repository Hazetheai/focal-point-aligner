# Web UI

React + Vite frontend for Focal Point Aligner.

Do not start this folder on its own. From the **repo root**:

```bash
npm run dev
```

That launches the API and this app together. See the root `README.md`.

Theme helpers live in `src/theme.js` (light / dark / system). CSS variables are in `src/index.css` under `[data-theme]`.
