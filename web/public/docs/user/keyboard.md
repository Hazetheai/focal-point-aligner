# Keyboard shortcuts

Hotkeys are **tab-scoped**: only the chips shown for the current tab do anything.

| Key | Action |
|-----|--------|
| Enter | Original: save+next · Preview: commit draft (when dirty) |
| Space | Original: skip · Preview video: play/pause |
| ← → | Navigate (Preview can Wrap) |
| X / Shift+middle click | Discard |
| D | Duplicate (Original) |
| Del | Clear focal (images) / clear all keyframes (videos) |
| H / G / I | Home focal+scale / Grid / Mask |
| C | Compare (Preview) |
| `<` `>` or `,` `.` | Overlay neighbor (Preview) |
| 0–6 | Arrange slots |
| Backspace | Clear active numeric Arrange slot (confirm) |
| P / O / A | Preview / Orient / Arrange |
| R / E / Esc | Reset / Export / Opener |

Discard, Del, and Reset use destructive styling in the hotkey bar.
